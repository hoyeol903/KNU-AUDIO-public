2026-10-01 검증 결과다. 설정 기준은 data/channels.yaml이며 검토 CSV는 output/csv/knu-cms-validation.csv다. 이 문서 작성 당시 기본은 국문·영문·수학 3개였으며, 이후 학교 학사공지·전자공학부를 추가해 현재 기본은 5개다. 검증한 추가 채널은 ID 또는 --required-knu-cms 옵션으로 선택한다.

조직 수는 이 채널들의 organization_ids 합집합이다. 경북대 전체 조직 수가 아니며, 하나의 게시판을 여러 조직·채널이 함께 사용하는 경우도 있다. 최근 날짜가 확인된 대표 글을 골라 ID·목록 제목(말줄임 포함)·게시일과 상세가 일치하는지 검증했다. 다음 페이지 URL 구조는 모든 비어 있지 않은 목록에서 확인했지만, 모든 게시판의 실제 두 번째 페이지를 요청한 것은 아니다.

## 추가 확인할 곳

- 경상대학 · 공지사항 (notice-541aff0da509): 정상 빈 목록. 새 글이 올라오면 상세 구조를 다시 확인한다.
- 경상대학 자율학부 · 공지사항 (notice-78e12cb6bc22): 정상 빈 목록. 새 글이 올라오면 상세 구조를 다시 확인한다.
- CSV의 추가확인=필요에는 원래 채널 조사에서 남긴 대상·메뉴 분류 메모도 포함한다. 이것은 요청 실패와 다르다. 일반 공지에는 대학원·다른 학년 대상이 섞일 수 있다. 아직 본문 대상별 선별 기능은 없다.

최종 수집 불가로 남은 KNU CMS 대상은 없다. unknown·접근 불가·다른 게시판 틀은 기존 카탈로그의 검토 표시를 유지했다. 이 결과로 모든 경북대 게시판의 수집 가능성을 확정한 것은 아니다.

## 보강한 내용

- 공식 CMS 별칭 도메인과 CEBA 같은 대문자 site/nav_code를 지원한다. 원문 URL의 대소문자는 유지하고 DB ID만 소문자로 저장한다.
- 자연과학대학/지구시스템과학부, 식품생물공학과/식품생물공학전공은 같은 원문 게시판으로 묶인다. 한 번 요청하고 모든 논리 channel_ids를 저장한다. 기존의 상세 생략 글도 연결을 추가하면서 본문 해시와 확인 시각을 유지한다.
- 의생명융합공학과 구형 스킨: 목록의 등록일 열, YYYY/MM/DD 날짜, h2 상세 제목, 표의 작성일·첨부를 원문 구조로 읽는다. 임의의 숫자 열을 날짜로 추측하지 않는다. 실제 다음 페이지도 확인했다.
- HTTP 요청은 한 연결로 순차 처리한다. /HOME/을 사용하는 공식 CMS 별칭 호스트도 공통 간격을 적용한다. 요청 간격 1초, 추가 재시도 최대 2회를 유지한다.

## 실제 검증·저장

필수 채널 전체 대표 검증과 구형 보완 확인은 HTTP 262회였다. 중간 실패와 수정 근거는 data/runs/knu-cms-validation-20261001-initial.json 및 최종 보고서 repairs에 남아 있다. 최종 결과는 data/knu-cms-validation.json, HTML과 URL 메타데이터는 collector/tests/fixtures/knu-cms/expansion/에 저장했다. 받은 HTML은 Client가 인코딩을 판정한 문자열이며, 응답 바이트·헤더 전체 보관을 뜻하지 않는다.

추가 실제 수집은 4개 논리 채널/3개 원문 게시판의 첫 페이지로 제한했다.

| 원문 게시판 | 목록·상세 성공 | 첫 저장 | HTTP 요청 | 경과 초 | 오류 |
|---|---:|---:|---:|---:|---:|
| 자연과학대학 (지구시스템과학부와 공유) | 10 | 10 | 11 | 15.430 | 0 |
| IT대학 | 10 | 10 | 11 | 13.081 | 0 |
| 의생명융합공학과 | 29 | 29 | 30 | 42.369 | 0 |

DB 4,330→4,379개. 신규 저장 49개는 초기 적재이며 당일 신규 후보는 0개다. 모든 세 게시판은 다음 페이지가 남아 max-pages=1에서 중단해 truncated=true, 종료 코드 1이다. 전체 과거 글 적재 완료·일일 확인 범위 완료를 뜻하지 않는다. 보고서: data/runs/knu-cms-expansion-sample-20261001.json.

## 실행

```bash
# 기본 5개 채널 일일 실행
python -m collector.run

# 검증한 추가 채널: 첫 페이지로 제한한 검증 실행
python -m collector.run --channel-id notice-ddb70636c525 --max-pages 1

# 검증된 필수 KNU CMS 전체 선택: 먼저 제한 실행
python -m collector.run --required-knu-cms --max-pages 1

# 목록·대표 상세 검증 갱신 (DB에는 저장하지 않음)
python -m collector.verify_knu_cms

# 저장된 HTML과 HTTP 대체 응답으로 테스트: 실제 인터넷 호출 없음
python -m pytest -q
```

--required-knu-cms는 검증된 채널만 선택하고 같은 원문 게시판은 한 번 처리한다. CSV는 검토용이며 설정을 바꾸는 입력 파일이 아니다. 주소를 변경한 채널은 검증을 다시 받아야 선택할 수 있다. 새 게시판은 운영 기준이 없어서 초기 적재를 한다. 상한 없이 실행하면 과거 글 전체를 순회하므로 전체 129개 게시판의 초기 적재 시간은 아직 측정하지 않았다. 기본 채널을 CMS 전체로 바꾸거나 초기 적재 완료 시각을 임의로 등록하지 않았다.

테스트 72개 통과. 모든 검증 대상의 실제 HTML을 순회하는 오프라인 회귀 확인, 구형 날짜·구조, 별칭 간 요청 간격, 미검증/주소 변경 채널 거부, 공유 게시판 중복 제거와 이력 보존을 포함한다.

다음 추천은 학교 공통 학사공지(knu-wbbs)와 전자공학부 등 다른 틀의 필수 게시판 지원이다. 새 CMS 채널은 필요한 최근 이력부터 운영을 시작할지, 전체 과거 적재를 배치로 진행할지 초기 범위를 정한 뒤 예약 실행에 연결한다.
