# 채널 검토 결과 (2026-09-30)

`channel-review.html`을 브라우저에서 열면 학과 선택에 따른 공통·소속 필수 채널, 선택 채널, 제외 채널을 확인할 수 있다. `확인할 곳` 탭에는 전체 조직의 미확인·접근 실패·분류 유보 항목이 나온다. 학과 선택은 소속 대학의 공지를 자동 포함한다. 선택 채널은 전체 목록에서 검색할 수 있다. 이것은 검토 도구이며 서비스 플레이어 또는 수집기는 아니다.

현재 앱 카탈로그에서는 장학·취업 등 optional 공지 73개를 선택 목록에서 뺐다. 사용자는 본인 학과 필수 공지에 더해 다른 학과의 필수 공지와 식당 채널을 선택할 수 있다. 아래 날짜가 붙은 조사 집계는 당시 기록이다.

## 분류 정책

- 학교 학사공지: 모두 필수.
- 학부·학사·학년 공지 및 조직 대표 공지: 해당 학과와 소속 대학 학생의 필수 채널 초안.
- 장학·취업·활동·국제교류 등: 선택. 장학과 수강이 섞인 게시판은 채널만으로 글을 분리할 수 없어 검토 표시.
- 대학원·BK21·교육대학원 전용: 신입생 채널에서 제외하며 원문 주소는 보존.
- 일반·대상 혼합 공지와 목록 여부 미확정 링크: 확인할 곳에 표시. 메뉴 이름에 근거한 초안이며 개별 공지의 실제 수신 대상은 아직 분류하지 않았다.
- 홈페이지가 같은 학부·전공은 채널을 공유한다. 소속별 이름이 중복되므로 ID로 구분한다. 2027 모집 편제와 현재 공식 조직의 대응은 추가 확인 필요.

## 조사 범위와 판정

기존 조사에서 저장한 홈페이지·대표 게시판 HTML과 후보 메뉴를 확장했다. 링크 텍스트가 공지·장학·취업 등에 해당하는 주소를 확인했고, 학사 안내 같은 일반 소개 페이지는 제한했다. 메뉴에 없는 게시판·로그인 게시판이나 모든 교내 기관을 전수 탐색한 것은 아니다. 학교 학사공지와 식당 메뉴는 앞선 조사 결과를 재사용했다. 대학·학과 홈페이지 밖의 국제교류 등 모든 중앙 부서 채널을 조사했다고 해석하지 않는다.

`found`: HTML 목록 또는 기존 원본으로 확인. `needs-check`: 후보 링크는 있으나 목록 여부 또는 메뉴 내용 미검증. `unreachable`: 최종 요청 실패. `missing`: 공식 조직 목록에서 독립 게시판 주소 미확인. `template: unknown`은 시스템 분류 유보이며 접근 실패와 별개다. 새로 확인한 원본은 `collector/tests/fixtures/channels/`, 요청 사실은 `channel-audit.json`에 있다. 인코딩과 SHA-256을 기록했다.

## 사용자가 확인할 방법

1. 화면에서 **확인할 곳**을 누르고 `주소 미확인` 또는 `접근 실패`를 선택한다.
2. 원문·홈페이지·단과대학 홈페이지·학교 공식 안내 링크를 연다.
3. 발견한 주소와 메모를 행의 입력란에 적고 **확인 메모 내려받기**로 JSON을 저장한다. 입력은 브라우저에 임시 보관되며 자동으로 YAML을 수정하지 않는다. YAML 반영은 새 주소 검증 후 한다.
4. 저장한 JSON을 함께 주면 해당 조직·채널에 연결할 수 있다. 메모를 입력했다고 조사 상태가 확인 완료로 바뀌지는 않는다.
