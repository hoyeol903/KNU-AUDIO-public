# 공개 저장소 이전 점검

점검일: 2026-10-09

## 이전 방식

- 기존 `hoyeol903/KNU-AUDIO`는 비공개 보관한다.
- 정리한 최신 파일만 `hoyeol903/KNU-AUDIO-public`에 첫 커밋으로 올린다. 기존 Git 이력·PR·Actions 기록·artifact는 복사하지 않는다.
- 홈페이지는 GitHub Pages로 배포한다. 기존 Cloudflare 사이트는 새 사이트 확인 전까지 유지한다.
- 새 홈페이지: https://hoyeol903.github.io/KNU-AUDIO-public/

## 데이터 처리

저장 시 명시적인 학번, 주민등록번호, 010 휴대전화와 학번에 연결된 성명을 `[개인정보 가림]`으로 바꾼다. 원문의 날짜·마감·장소·조건과 학교 공식 연락처는 유지한다. 검수는 가린 원문을 기준으로 한다. DB 및 items의 필드 형식은 유지한다.

현재 자료에도 같은 처리를 적용했다. 명단 관련 후보 97건의 저장된 본문을 검토해 17건의 개인 명단 부분을 제거했다. 전체 DB에 대해서도 표 형태·부분 가림 학번, 이름만 있는 선발 결과, 첨부 암호를 추가 점검하고 가렸다. 실제 첨부파일은 포함하지 않고 fixture의 내장 이미지 33개를 제거했다. 교수·학교 담당자의 공식 연락처와 연구실 안내는 유지한다. 정규식이 모든 형태의 개인정보를 보증하는 것은 아니므로 이후 새 수집 자료도 점검해야 한다.

## 배포 및 운영

Settings → Pages → Source를 GitHub Actions로 설정한다. `deploy.yml`이 앱 화면·자료와 하루 배경음악 한 곡을 게시한다. Cloudflare 배포용 Secret은 필요하지 않다. Kaggle용 Secret과 운영 변수를 새 저장소에 따로 등록한다.

외부 예약 서비스의 실행 주소와 GitHub 토큰의 저장소 접근 권한은 새 저장소에 맞춰 변경해야 한다. 변경 전까지 새 저장소의 자동 수집은 꺼 둔다. 팀원은 새 저장소를 복제해서 작업하며, 기존 저장소의 전체 이력을 다시 밀어 넣지 않는다.

## 검증과 한계

수집기·브리핑 테스트: 383개 통과, 2개 건너뜀(로컬 FFmpeg 없음). 실제 학교 수집이나 GPU 음성 재생성은 이번 이전 점검에서 실행하지 않는다. 기존 생성 자료를 배포한다. 과거 권리가 확인되지 않은 음악은 새 파일 목록에 없으며, 현재 배경음악은 THIRD-PARTY.md의 출처·라이선스를 따른다.
