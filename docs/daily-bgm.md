# 하루 배경음악 — YouTube 30곡

2026-10-09 YouTube 스튜디오에서 분위기 ‘밝음’과 ‘저작자 표시 필요 없음’을 확인한 30곡으로 교체했습니다. [공식 이용 안내](https://support.google.com/youtube/answer/3376882?hl=ko)를 참고하세요. 저작권이 없는 곡이라는 뜻은 아닙니다. 스튜디오 이용 약관은 직접 만든 콘텐츠에 음악을 사용하는 것을 허용하지만 원곡 파일만 독립적으로 제공·배포하는 것을 금지합니다. YouTube 외부 이용에 대한 보증으로 해석하지 않습니다.

공개 `assets/bgm/catalog.json`에는 제목·아티스트·라이선스·실제 재생 길이·SHA-256만 보관합니다. 기존 Incompetech MP3 30개와 공개 앱의 단독 음악 파일을 제거했습니다. Git 이력은 다시 쓰지 않습니다.

원곡은 `jeongwonbahk/knua-youtube-bgm-private` 비공개 저장소의 `assets/youtube-20261009` 브랜치 `music/`에 보관하도록 구성했습니다. 배포에서는 이 저장소에만 접근하는 읽기 전용 SSH deploy key를 `KNUA_BGM_DEPLOY_KEY` 시크릿으로 등록해야 합니다. 원곡 업로드와 키 연결은 명시적 승인 후 완료하는 활성화 단계입니다. 준비 전에는 이 PR을 머지하지 마세요.

Pages 작업은 원곡을 `.cache/youtube-bgm`에만 받고 `site/`의 브리핑 음성과 FFmpeg로 혼합합니다. 원곡 폴더는 배포 artifact에 포함하지 않습니다. 한국 날짜와 파일명 목록으로 고른 곡의 해시를 검증하고, 음성이 없는 결과는 엄격한 배포 모드에서 실패시킵니다. 음악 음량은 10%이며 각 혼합본 길이는 원래 음성 길이에 맞춥니다. 같은 날짜와 목록이면 같은 곡이고 다른 날짜에도 같은 곡이 뽑힐 수 있습니다. 자정 자동 교체가 아니라 다음 배포 시 반영됩니다.

각 segment의 `audio`는 음성 전용 파일, `audio_bgm`은 혼합본입니다. 최상위 `bgm`에 곡 정보가 기록됩니다. ♪ 버튼은 현재 위치를 유지해 두 파일을 전환합니다. 혼합본 로드 실패는 같은 위치의 음성 전용 파일로 대체합니다. 음악도 음성과 함께 일시정지·속도 변경·음소거됩니다. 별도의 음악 전용 재생기나 음악 다운로드는 없습니다. 기기 TTS 대체에는 음악을 넣지 않습니다.

음악은 구간마다 처음부터 시작하므로 이전 별도 반복 음악처럼 구간 사이에 연속 재생되지는 않습니다. 음성 전용 저장 기능은 원래 음성 파일을 사용합니다. 혼합본 캐시는 음성·원곡 해시와 레시피로 결정하며 다른 혼합본은 성공적으로 metadata를 갱신한 뒤 정리합니다.

로컬에서는 원곡이 없어도 이미 생성된 혼합본으로 미리보기할 수 있습니다. 새로 생성하려면:

```bash
python -m tools.daily_bgm --source-dir /비공개/음악/music --require-source
```

원곡이 없는 일반 로컬 내보내기는 대기 상태를 기록하고, `--require-source` 배포는 실패합니다. FFmpeg 외의 새 의존성이나 TTS 재생성은 필요하지 않습니다. 공개 브랜치에는 현재 음성을 사용한 혼합 예시도 포함합니다.
