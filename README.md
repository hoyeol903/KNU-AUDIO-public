# 크누아 KNU AUDIO

**등굣길에 듣는 오늘의 경북대 소식.**

학교·단과대학·학과 게시판에 흩어진 공지부터 날씨, 학식, 학사일정까지 한곳에서 확인하는 경북대학교 학생용 웹 서비스입니다. 내 학과와 관심 게시판, 자주 가는 식당을 고르면 필요한 소식을 짧은 음성 브리핑으로 듣고, 공지를 저장하거나 함께할 모임을 찾을 수 있습니다.

경북대학교 2027학년도 신입생을 주요 대상으로 만드는 AI CRAFT 해커톤 프로젝트입니다. 브리핑은 개인별 1~2분을 목표로 하며, 선택한 게시판·식당과 안내할 공지 수에 따라 실제 재생 시간은 달라집니다.

## 이렇게 사용해요

1. 이름과 학과를 입력하고, 함께 볼 게시판과 식당을 고릅니다. 이름·학과 설정은 계정 가입이 아니라 이 브라우저에 저장하는 개인 설정입니다.
2. 홈에서 오늘 소식, 날씨, 이번 주 일정과 학식을 확인하고 브리핑을 재생합니다.
3. 필요한 공지는 상세 화면에서 저장하고 **내 게시판 → 저장한 공지**에서 다시 봅니다.
4. 캘린더에서 학사일정과 내 일정을 확인하거나, 모임에서 스터디·과팅·소모임 모집글을 읽고 참가를 신청합니다.

### 브리핑과 재생

- 내 게시판과 식당 선택에 맞는 음성 구간을 재생 목록으로 구성합니다. 같은 공지가 여러 게시판에 포함돼도 중복 재생을 줄입니다.
- 선택한 공지가 없으면 짧은 공지 없음 안내를 듣고, 마무리 인사 전에 공통 응원 멘트를 듣습니다. 응원 문장은 [관리자 화면](https://hoyeol903.github.io/KNU-AUDIO-public/admin/)에서 저장하면 다음 정기 음성 생성부터 반영됩니다. 서버가 연결되지 않으면 마지막 적용 문장을 유지합니다.
- 대본과 말풍선을 음성 재생 위치에 맞춰 표시합니다. 파일에 문장별 타이밍 정보가 있으면 그 정보를 사용합니다.
- 오늘 수집 자료와 음성 날짜가 달라도 자료 기준일과 3일 이내 차이가 나는 최신 음성은 날짜를 표시해 제공합니다. 새 음성을 기다리는 동안 지난 브리핑을 먼저 들을 수 있습니다.
- 재생 요청이 거절되면 재생 상태를 되돌려 다시 시도할 수 있게 하고, 기기가 음성을 멈추면 화면 상태도 맞춥니다. 잠금 화면·이어폰의 재생 조작은 Media Session으로 연결하며 실제 지원 범위는 기기와 브라우저에 따라 다릅니다.
- 하루 BGM은 아침용 어쿠스틱·피아노·재즈 등 밝고 편안한 새 원본 30곡 중 한국 날짜를 기준으로 한 곡을 선택해 다음 배포에 반영합니다. 음성 구간이 바뀔 때 음악을 계속 재생하고, 사용자 일시정지나 브리핑 종료 때 함께 멈춥니다. 음악은 별도로 끌 수 있습니다.

현재 대본은 `qwen3:4b-instruct-2507-q4_K_M`, 음성은 **Qwen3-TTS 1.7B CustomVoice의 Sohee**를 기본으로 사용합니다. 공지의 말투와 해요체를 보정하고, 고정된 아침 인사도 다른 구간과 같은 Sohee 음성으로 생성합니다. 설정 변경은 다음 음성 생성부터 적용됩니다. 음성 파일 없이 대본만 있는 구간은 지원되는 브라우저의 음성 기능으로 읽을 수 있습니다.

### 모임을 찾고 모집하기

모임 첫 화면은 **스터디·과팅·소모임** 세 구역으로 나뉩니다. 구역을 누르면 해당 목록으로 이동하며, 모집글을 누르면 소개와 참가 정보를 볼 수 있습니다.

| 구분 | 작성하는 정보 |
|---|---|
| 스터디 | 공부 주제·목표, 설명·진행 방식, 모집 인원, 참가 수준·준비물 |
| 소모임 | 주요 활동, 설명·활동 방식, 모집 인원, 참가 조건·준비물·비용 |
| 과팅 | 우리 팀, 팀별 인원(2:2·3:3·4:4), 희망 상대·학과, 팀 소개·만남 계획 |
| 공통 | 제목, 일정, 장소·온라인 여부, 참가 문의용 인스타그램 또는 오픈카카오톡 링크 |

실제 모집글과 신청은 **Cloudflare Workers API + D1**에 저장되며 다른 브라우저에서도 모집글을 볼 수 있습니다. 작성자는 글을 수정·마감·재개·삭제하고 신청 내역을 확인합니다. 신청자는 신청 내용을 수정하거나 취소할 수 있고, 신청자의 이름·메시지·연락 링크는 모집자에게만 공개됩니다. 신청 접수는 참가 확정을 뜻하지 않습니다.

모임 화면에는 실제 모집글만 보입니다. 이전에 보여 주던 예시 모집글은 없앴습니다.

### 어디에 저장되나요?

| 자료 | 저장 위치와 범위 |
|---|---|
| 이름·학과, 게시판·식당 선택, 저장한 공지, 개인 일정 | 이 브라우저의 `localStorage`. 다른 기기로 동기화되지 않으며 브라우저 데이터 삭제·앱 설정 초기화 때 사라집니다. |
| 공유 모집글·신청 | Cloudflare D1. 다른 사용자가 모집글을 볼 수 있으며 신청 정보는 모집자에게만 제공합니다. |
| 모집글·신청 관리 권한 | 브라우저별 무작위 토큰으로 구분합니다. 토큰을 잃으면 기존 작성·신청 권한을 복구할 수 없습니다. |

현재 이름·학과는 사용자가 직접 입력하는 정보입니다. **회원 계정 로그인, 경북대 재학생 인증, 기기 간 개인 설정 동기화는 아직 제공하지 않습니다.** 모임 권한 토큰은 일반 앱 설정 초기화와 분리해 보관하지만, 브라우저 데이터를 지우면 함께 삭제됩니다. 자세한 API와 권한 설명은 [모임 연결 안내](docs/community.md)를 참고하세요.

## 서비스 구성과 데이터 흐름

홈페이지는 **GitHub Pages**, 공유 모집글 API와 DB는 **Cloudflare Workers + D1**, 대본·음성 생성은 **Kaggle GPU**에서 실행합니다.

```text
경북대 공지 · 날씨 · 학사일정 ──▶ GitHub Actions의 collector
여섯 식당의 주간 식단 ─────────▶ 로컬 갱신
                                      │
                            data/db/ · data/raw/<날짜>/
                                      │
                         ┌────────────┴────────────┐
                         ▼                         ▼
               Kaggle 대본·Sohee 음성       collector.export_app
                         └────────────┬────────────┘
                                      ▼
                                  output/app/
                                      ▼
                             GitHub Pages 홈페이지
                                      │
                           모집글·신청 조회 및 저장
                                      ▼
                        Cloudflare Workers API ──▶ D1
```

- 필수 공지 수집 대상은 고유 게시판 **136개**, 논리 채널 **139개**입니다. 날씨·학사일정은 공지 수집과 함께 갱신합니다.
- 학식은 **여섯 식당의 주간 자료를 로컬에서 갱신**합니다. 식단이 없거나 수집에 실패한 상태를 구분하고, 이전에 받은 주간 표를 사용하는 경우 받은 날짜를 표시합니다.
- 홈페이지와 공지 자료는 정적 파일로 배포합니다. 홈페이지에 방문할 때마다 모든 공지를 다시 수집하거나 TTS를 새로 생성하지 않습니다.
- GitHub Pages 자체에 공유 DB가 생기는 것은 아닙니다. 모임는 별도 Cloudflare API에 연결하며, 연결 오류 때는 오류를 표시하고 실제 저장 성공으로 처리하지 않습니다.

| 경로 | 역할 |
|---|---|
| `collector/` | 공지·날씨·학사일정 수집, 저장과 앱용 데이터 생성 |
| `data/db/notices.json` | 누적 공지와 확인 기록 |
| `data/raw/<날짜>/` | 날짜별 브리핑 입력 `items.json`과 출처별 자료 `context.json` |
| `briefing/` | 대본 생성, 규칙 검수, 음성 생성과 앱 내보내기 |
| `tools/knua-app.html`, `web/player/` | 웹 화면과 플레이어 구현 |
| `output/app/` | GitHub Pages 배포용 화면과 데이터 |
| `community/`, `migrations/` | Cloudflare 공유 API, Worker와 D1 스키마 |
| `data/runs/` | 수집·음성 처리 실행 보고서 |

## 개발 환경과 로컬 미리보기

Python **3.11 이상**과 공유 API 검사에 필요한 Node.js **22.13 이상**을 사용합니다. CI는 Python 3.11과 Node.js 24에서 실행합니다.

```bash
git clone https://github.com/hoyeol903/KNU-AUDIO-public.git
cd KNU-AUDIO-public
python -m pip install -r requirements.txt
```

저장된 자료로 화면을 다시 만들고 로컬에서 엽니다. 아래 내보내기는 학교 사이트를 요청하지 않습니다.

```bash
python -m collector.export_app
python -m http.server 8000 --directory output/app
```

[http://127.0.0.1:8000](http://127.0.0.1:8000)을 엽니다. 단순 정적 서버는 공유 API를 실행하지 않습니다. 로컬 모임 API 개발과 D1 설정은 [모임 연결 안내](docs/community.md)를 참고하세요.

오프라인 검사는 저장된 fixture와 메모리 DB를 사용하며 학교 수집이나 실제 GPU 음성 생성을 실행하지 않습니다.

```bash
python -m pytest -q -p no:cacheprovider collector/tests briefing/tests community tools/tests
python docs/check_channels.py
node --test tests/*.test.mjs collector/tests/*.mjs community/test_api.mjs community/test_worker.mjs
node tools/tests/personal-greeting.cjs
```

실제 음성 품질, 휴대폰 재생, 잠금 화면·이어폰 동작은 별도 기기 확인이 필요합니다.

## 수집·음성 생성·배포 운영

### 매일 공지 수집

매일 한국시간 **01:07**에 cron-job.org가 GitHub Actions의 `매일 경북대 자료 수집` 실행을 요청합니다. GitHub 자체 수집 예약은 제거했으며 외부 예약 서비스와 실행 서버 상황에 따라 시작이 늦어질 수 있습니다.

최근 30일 공지 목록을 확인하고 새 글·변경된 글·마감이 남은 글 등을 다시 확인합니다. 오늘 본문을 확인하지 못한 선정 후보와 이미 마감한 글은 브리핑에서 제외합니다. 실패 출처는 실행 보고서와 `output/app/data/collection-failures.csv`에 남으며 실패한 게시판만 재수집할 수 있습니다.

실제 수집·갱신이 필요한 경우에만 실행합니다.

```bash
python -m collector.run --all-required --write-items --collect-extras --skip-meals
python -m collector.run --retry-failed --write-items
```

### 주간 학식과 Kaggle 브리핑

- 매주 월요일 오전 9시(한국시간)에 학식 갱신 이슈 알림을 보냅니다. `python -m tools.update_meals`는 실제 식단 수집, 앱 내보내기, 브랜치 push와 PR 생성을 진행하며 PR은 별도로 병합합니다. 이 명령만으로 음성을 재생성하지 않습니다.
- `Kaggle GPU 브리핑 생성`은 저장된 날짜별 입력으로 대본·음성을 생성합니다. 검증한 결과를 `output/app/data/briefing/`에 게시하며, 수동 실행의 `publish`는 기본적으로 켜져 있습니다.
- 수집 후 자동 음성 생성은 저장소 변수 `ENABLE_KAGGLE_BRIEFING=true`와 Secret `KAGGLE_API_TOKEN`으로 연결합니다. 입력 내용이 같으면 생성을 건너뛰며, 모델·대본 캐시와 저장한 생성 결과를 재사용합니다.
- 기본 계정의 GPU 한도가 부족하면 설정된 보조 Kaggle 계정을 선택할 수 있습니다. 보조 계정은 선택 사항이며 음성 모델 데이터셋 공유가 필요합니다.
- GitHub에서 실행을 취소하면 해당 Kaggle 커널을 삭제하도록 연결했습니다. 완료 결과 회수용 워크플로도 제공합니다. 생성 소요 시간은 입력량, 캐시와 GPU 대기에 따라 달라집니다.

대본에는 원문 기반 규칙 검수를 적용하지만, 날짜·대상·장소·신청 조건의 의미를 완전히 검증하는 시스템은 아닙니다. 중요한 조건은 원문 링크에서 확인하세요. 자세한 생성·검수 범위는 [Kaggle 브리핑](docs/briefing-kaggle.md)과 [브리핑 통합](docs/briefing-integration.md)을 참고하세요.

### GitHub Pages와 공유 API

`.github/workflows/deploy.yml`이 `output/app/index.html`, 개인정보 안내와 `output/app/data/`를 GitHub Pages에 올립니다. 앱 자료가 바뀐 main push, 수집 워크플로 완료, 또는 수동 실행으로 배포하며, 일시적인 Pages 배포 오류는 한 번 다시 시도합니다. 저장소 **Settings → Pages → Source**는 **GitHub Actions**로 설정합니다.

현재 홈페이지는 [hoyeol903.github.io/KNU-AUDIO-public](https://hoyeol903.github.io/KNU-AUDIO-public/)입니다. 홈페이지 배포에는 별도 Cloudflare Secret이 필요하지 않습니다. 공유 API는 `community/worker.mjs`와 D1의 `COMMUNITY_DB` 바인딩을 사용하며, API 주소와 허용 출처 설정은 [모임 연결 안내](docs/community.md)에 있습니다.

## 개인정보와 라이선스

명시적인 학번·주민등록번호·010 휴대전화와 학번에 연결된 성명은 저장 전에 가립니다. 원문의 날짜·마감·장소·조건과 학교 공식 연락처는 유지하며, 검수 기준은 **개인정보를 가린 원문**입니다. 자동 가림이 모든 개인정보 형태를 보증하지는 않으므로 새 자료의 공개 적합성도 확인합니다. 자세한 기준은 [공개 준비 점검](docs/public-readiness.md)에 있습니다.

방문 통계는 Google Analytics의 **크누아 홈페이지** 속성에서 확인합니다. 이름·학과·식당 선택·피드백 내용은 Analytics로 보내지 않고 향상된 측정과 광고 기능은 끕니다. 안내는 [개인정보 안내 화면](tools/privacy.html)에 있습니다. 공유 모집글과 참가 문의 링크는 공개되므로 개인 설정의 브라우저 저장과 구분합니다.

코드는 [MIT 라이선스](LICENSE)를 따릅니다. 아래 외부 자료에는 MIT 라이선스가 적용되지 않습니다.

- **BGM**: Kevin MacLeod의 Incompetech 아침용 원본 30곡, **CC BY 4.0**. 2026-10-09 기존 30곡을 새 목록으로 전부 교체했습니다. 원본 공개 재배포가 가능하며 작곡가·출처·라이선스·수정 여부 표시를 보존합니다. 곡별 출처·원본 링크·파일 검증 정보는 [음악 카탈로그](assets/bgm/catalog.json)에 있고, 앱 설정에서도 당일 BGM의 출처를 볼 수 있습니다.
